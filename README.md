# Abhishek Verma Portfolio

A modern, responsive personal portfolio built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Before deployment

Replace the clearly marked placeholder GitHub and LinkedIn buttons in `src/App.jsx` with your real profile URLs.

The portfolio intentionally does not invent a hosted resume URL, project URLs, metrics, awards, certifications, or other facts that are not present in the supplied resume.
